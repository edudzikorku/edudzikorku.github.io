GhanaPostGPS Converter

Ready - paste codes or upload a CSV, then run the conversion.

Looks up each code against the public GhanaPostGPS service, one at a time with a short pause between requests. Repeated codes are only looked up once. Codes that can't be found still appear in the results with empty coordinates and a status note.
